# sing-box 服务端配置与部署指南

> 本文档用于记录 sing-box 服务端的完整安装部署流程与配置细节。

---

## 一、 系统环境要求

在开始部署之前，请确保服务器具备以下基础环境：

* **推荐操作系统**：[例如：Debian 12 / Ubuntu 22.04 LTS]
* **硬件建议**：[例如：1 CPU / 512MB RAM / 10GB 硬盘]
* **网络与防火墙设置**：
  * 开放端口 `[端口号1]` （用途：[例如：主要节点端口]）
  * 开放端口 `[端口号2]` （用途：[例如：TLS 证书申请端口]）
* **本人使用的是Debian13系统进行的配置，主要的考量就是Debian的稳定性高以及占用小。如果使用的是其他的系统，不保证本文档的配置教程适合你**
* **本次配置选择的sing-box版本是1.14.3，考虑到sing-box的各种参数更新比较快，请使用与本文档相同的版本**
* **本次配置选择的sing-box版本是1.14.3，使用的是Hysteria2和REALITY协议，hy2协议使用自签证书的方式，不需要购买域名，使用域名的配置不在本次的配置范围内**

---

## 二、 安装 sing-box

### 1. 使用官方软件源安装

在终端运行以下命令：

```bash
sudo apt update && apt upgrade -y

sudo mkdir -p /etc/apt/keyrings &&
   sudo curl -fsSL https://sing-box.app/gpg.key -o /etc/apt/keyrings/sagernet.asc &&
   sudo chmod a+r /etc/apt/keyrings/sagernet.asc &&
   echo '
Types: deb
URIs: https://deb.sagernet.org/
Suites: *
Components: *
Enabled: yes
Signed-By: /etc/apt/keyrings/sagernet.asc
' | sudo tee /etc/apt/sources.list.d/sagernet.sources &&
   sudo apt-get update &&
   sudo apt-get install sing-box

### 2. 使用官方软件源安装

curl -fsSL https://sing-box.app/install.sh | sh 使用官方最新的稳定版本

curl -fsSL https://sing-box.app/install.sh | sh -s -- --beta 使用官方最新的beta版本

curl -fsSL https://sing-box.app/install.sh | sh -s -- --version <version> 指定版本

3安装完成之后使用 sing-box version 检查版本

export VPS_IP="替换为你的VPS公网IPv4"

直接复制粘贴以下整组命令：
(
set -e
umask 077

# 创建证书与私钥目录
install -d -m 700 /root/sing-box-private
install -d -o root -g sing-box -m 750 /etc/sing-box/tls

# 生成私有 CA 密钥
openssl ecparam -genkey -name prime256v1 -noout \
  -out /root/sing-box-private/ca.key

# 生成有效期 10 年的私有 CA 证书
openssl req -new -x509 -sha256 \
  -key /root/sing-box-private/ca.key \
  -days 3650 \
  -out /etc/sing-box/tls/ca.crt \
  -subj "/CN=Private Sing-box CA" \
  -addext "basicConstraints=critical,CA:TRUE" \
  -addext "keyUsage=critical,keyCertSign,cRLSign"

# 生成 Hysteria2 服务器私钥
openssl ecparam -genkey -name prime256v1 -noout \
  -out /etc/sing-box/tls/server.key

# 创建证书签名请求
openssl req -new \
  -key /etc/sing-box/tls/server.key \
  -out /root/sing-box-private/server.csr \
  -subj "/CN=${VPS_IP}"

# 设置 IP 地址证书扩展
cat > /root/sing-box-private/server.ext <<EOF
[server_cert]
basicConstraints=critical,CA:FALSE
keyUsage=critical,digitalSignature
extendedKeyUsage=serverAuth
subjectAltName=IP:${VPS_IP}
EOF

# 使用私有 CA 签发 365 天的服务器证书
openssl x509 -req \
  -in /root/sing-box-private/server.csr \
  -CA /etc/sing-box/tls/ca.crt \
  -CAkey /root/sing-box-private/ca.key \
  -CAcreateserial \
  -out /etc/sing-box/tls/server.crt \
  -days 365 \
  -sha256 \
  -extfile /root/sing-box-private/server.ext \
  -extensions server_cert

# 设置文件权限
chown root:sing-box /etc/sing-box/tls/server.key
chmod 640 /etc/sing-box/tls/server.key
chmod 644 /etc/sing-box/tls/*.crt

# 验证证书链及 IP 地址
openssl verify \
  -CAfile /etc/sing-box/tls/ca.crt \
  -verify_ip "$VPS_IP" \
  /etc/sing-box/tls/server.crt
)

执行之后应当出现：

/etc/sing-box/tls/server.crt: OK


在配置 REALITY 之前，先验证 VPS 可以通过 TLS 1.3 连接我们选择的握手目标：

timeout 10 openssl s_client \
  -connect www.microsoft.com:443 \
  -servername www.microsoft.com \
  -tls1_3 -brief </dev/null

  （可以替换为你想要选择的网站，尽量选择知名的，访问通畅的）

使用以下命令生成Hysteria2和reality双协议配置：
(
set -e
umask 077

# 生成 Hysteria2 密码
HY2_PASSWORD="$(openssl rand -hex 32)"

# 生成 VLESS UUID
VLESS_UUID="$(sing-box generate uuid)"

# 生成 REALITY 密钥对
REALITY_KEYS="$(sing-box generate reality-keypair)"
REALITY_PRIVATE="$(printf '%s\n' "$REALITY_KEYS" | awk '/^PrivateKey:/ {print $2}')"
REALITY_PUBLIC="$(printf '%s\n' "$REALITY_KEYS" | awk '/^PublicKey:/ {print $2}')"

# 生成 REALITY Short ID
REALITY_SHORT_ID="$(openssl rand -hex 8)"

# 验证生成结果
test -n "$HY2_PASSWORD"
test -n "$VLESS_UUID"
test -n "$REALITY_PRIVATE"
test -n "$REALITY_PUBLIC"
test -n "$REALITY_SHORT_ID"
test -f /etc/sing-box/tls/server.crt

# 在临时文件中生成配置，避免密钥短暂暴露
TMP_CONFIG="$(mktemp /etc/sing-box/.config.XXXXXXXX)"

cat > "$TMP_CONFIG" <<EOF
{
  "log": {
    "level": "info",
    "timestamp": true
  },
  "inbounds": [
    {
      "type": "hysteria2",
      "tag": "hysteria2-in",
      "listen": "0.0.0.0",
      "listen_port": 443,
      "users": [
        {
          "name": "primary",
          "password": "${HY2_PASSWORD}"
        }
      ],
      "ignore_client_bandwidth": true,
      "tls": {
        "enabled": true,
        "alpn": ["h3"],
        "certificate_path": "/etc/sing-box/tls/server.crt",
        "key_path": "/etc/sing-box/tls/server.key"
      }
    },
    {
      "type": "vless",
      "tag": "reality-in",
      "listen": "0.0.0.0",
      "listen_port": 443,
      "users": [
        {
          "name": "primary",
          "uuid": "${VLESS_UUID}",
          "flow": "xtls-rprx-vision"
        }
      ],
      "tls": {
        "enabled": true,
        "server_name": "www.microsoft.com",
        "reality": {
          "enabled": true,
          "handshake": {
            "server": "www.microsoft.com",
            "server_port": 443
          },
          "private_key": "${REALITY_PRIVATE}",
          "short_id": [
            "${REALITY_SHORT_ID}"
          ]
        }
      }
    }
  ],
  "outbounds": [
    {
      "type": "direct",
      "tag": "direct"
    }
  ],
  "route": {
    "final": "direct"
  }
}
EOF

chown root:sing-box "$TMP_CONFIG"
chmod 640 "$TMP_CONFIG"
mv -f "$TMP_CONFIG" /etc/sing-box/config.json

# 在 root 专属目录保存客户端连接参数
cat > /root/sing-box-private/client-info.txt <<EOF
VPS_IP=${VPS_IP}

[Hysteria2]
Port=443/UDP
Password=${HY2_PASSWORD}
CA_Certificate=/etc/sing-box/tls/ca.crt

[VLESS-REALITY]
Port=443/TCP
UUID=${VLESS_UUID}
Flow=xtls-rprx-vision
ServerName=www.microsoft.com
RealityPublicKey=${REALITY_PUBLIC}
ShortID=${REALITY_SHORT_ID}
EOF

chmod 600 /root/sing-box-private/client-info.txt

echo "双协议配置已完成。"
)

检查并启动服务

首先进行配置校验：
sing-box check -D /var/lib/sing-box -C /etc/sing-box
如果出现任何错误，不要执行后续启动命令，先处理错误。

如果没有报错，再执行：
systemctl enable --now sing-box
然后查看：
systemctl status sing-box --no-pager

理想状态应当出现：
Active: active (running)


检查端口：
ss -lntup | grep ':443'
能看到 TCP 443 和 UDP 443 都由 sing-box 监听。

记得在 VPS 服务商控制台放行的端口，或者在服务器自己配置放行端口

ssh端口号	TCP	现有 SSH 管理
443	TCP	VLESS + REALITY
443	UDP	Hysteria2

如果 VPS 服务商提供云防火墙或安全组，请检查这三条入站规则。


这次部署会形成以下结构：
/etc/sing-box/
├── config.json
└── tls/
    ├── ca.crt
    ├── server.crt
    └── server.key

/root/sing-box-private/
├── ca.key
├── ca.srl
├── server.csr
├── server.ext
└── client-info.txt

ca.crt 是客户端需要信任的 CA 公共证书，可以安全地复制到你自己的设备。
ca.key 是 CA 私钥，绝对不能提供给客户端或其他人。
server.key 是 Hysteria2 服务器私钥，必须保密。
client-info.txt 保存两个节点的认证参数，必须保密。

当前服务器证书有效期为 365 天。到期前需要重新签发服务器证书

私有 CA 的密钥也要单独妥善保管，因为丢失它会影响未来的证书续期。不要直接公开或发送这些私钥文件。

在Windows powershell执行
scp -P ssh端口号 root@<VPS公网IPv4>:/etc/sing-box/tls/ca.crt .\ca.crt

关于HY2的公共证书，在下载到本地之后，放到sing-box客户端与配置文件同级的工作目录下，

配置 Hysteria2 证书自动续期
创建续期脚本
cat > /usr/local/sbin/sing-box-renew-cert <<'EOF'
#!/bin/bash
set -euo pipefail

IP="填入你的vps的ip"
DIR="/etc/sing-box/tls"
PRIVATE="/root/sing-box-private"

CERT="$DIR/server.crt"
KEY="$DIR/server.key"
CA="$DIR/ca.crt"
CAKEY="$PRIVATE/ca.key"
EXT="$PRIVATE/server.ext"

# 超过 30 天有效期时不续期
if openssl x509 -checkend 2592000 \
    -noout -in "$CERT"; then
    echo "证书有效期充足，无需续期。"
    exit 0
fi

# 创建临时目录
TMP="$(mktemp -d "$DIR/.renew.XXXXXXXX")"
trap 'rm -rf "$TMP"' EXIT

# 使用原有服务器私钥生成 CSR
openssl req -new \
    -key "$KEY" \
    -out "$TMP/server.csr" \
    -subj "/CN=$IP"

# 使用现有 CA 签发新证书
openssl x509 -req \
    -in "$TMP/server.csr" \
    -CA "$CA" \
    -CAkey "$CAKEY" \
    -CAcreateserial \
    -out "$TMP/server.crt" \
    -days 365 \
    -sha256 \
    -extfile "$EXT" \
    -extensions server_cert

# 验证证书签名和 IP 地址
openssl verify \
    -CAfile "$CA" \
    -verify_ip "$IP" \
    "$TMP/server.crt"

# 设置权限并替换证书
chown root:sing-box "$TMP/server.crt"
chmod 644 "$TMP/server.crt"

mv -f "$TMP/server.crt" "$CERT"

# 重新加载服务
systemctl restart sing-box

echo "Hysteria2 证书续期完成。"
EOF

赋予执行权限
chmod 700 /usr/local/sbin/sing-box-renew-cert

创建 systemd 定时服务
cat > /etc/systemd/system/sing-box-cert-renew.service <<'EOF'
[Unit]
Description=Renew sing-box TLS certificate

[Service]
Type=oneshot
ExecStart=/usr/local/sbin/sing-box-renew-cert
EOF

创建定时器：
cat > /etc/systemd/system/sing-box-cert-renew.timer <<'EOF'
[Unit]
Description=Weekly sing-box certificate renewal check

[Timer]
OnCalendar=weekly
RandomizedDelaySec=1h
Persistent=true

[Install]
WantedBy=timers.target
EOF

启用自动续期
systemctl daemon-reload
systemctl enable --now sing-box-cert-renew.timer

进行一次测试
systemctl start sing-box-cert-renew.service

查看运行结果
journalctl -u sing-box-cert-renew.service -n 30 --no-pager

由于你的证书刚签发不久，正常情况下会显示：
证书有效期充足，无需续期。

这样以后就不需要每年手动执行证书签发命令了。

重要： 自动续期依赖 /root/sing-box-private/ca.key。必须妥善保管这把 CA 私钥，最好额外保留一份加密的离线备份。


配置 nftables 防火墙
重要：配置防火墙有断开 SSH 的风险。先安排 5 分钟后的自动回滚，再应用规则。确认新的 SSH 连接正常后，才能取消回滚。

安装 nftables
apt update
apt install -y nftables

编写防火墙配置
cat > /etc/nftables.conf <<'EOF'
#!/usr/sbin/nft -f

flush ruleset

table inet filter {
    chain input {
        type filter hook input priority 0;
        policy drop;

        # 允许本机回环
        iifname "lo" accept

        # 允许已经建立的连接
        ct state established,related accept

        # 丢弃无效连接
        ct state invalid drop

        # 允许必要的 ICMP
        ip protocol icmp accept
        meta l4proto ipv6-icmp accept

        # DHCPv6 客户端通信
        udp sport 547 udp dport 546 accept

        # SSH 和 REALITY
        tcp dport { ssh端口号, 443 } accept

        # Hysteria2
        udp dport 443 accept
    }

    chain forward {
        type filter hook forward priority 0;
        policy drop;
    }

    chain output {
        type filter hook output priority 0;
        policy accept;
    }
}
EOF

检查语法
nft -c -f /etc/nftables.conf

设置自动回滚并应用
systemd-run --unit=nft-rollback \
  --on-active=5min \
  /usr/sbin/nft flush ruleset

应用规则：
nft -f /etc/nftables.conf

查看
nft list ruleset

在 Windows 上新开一个 PowerShell 窗口，重新连接：
ssh -p ssh端口号 root@ip

确认第二个 SSH 会话也能正常登录后，回到 VPS，执行：
systemctl stop nft-rollback.timer
systemctl enable nftables.service

查看防火墙是否仍然生效：
nft list ruleset

取消回滚并启用开机自启动
systemctl stop nft-rollback.timer
systemctl enable nftables.service

cat > /etc/sysctl.d/90-sing-box-udp.conf <<'EOF'
# UDP / QUIC socket buffer limits
net.core.rmem_max = 16777216
net.core.wmem_max = 16777216
EOF
